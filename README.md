# Petunjuk Eksekusi

## 1. Clone Repositori
```bash
git clone https://github.com/b3Peee/Studi-Komparatif-Empiris-Model-Generatif-Autoencoder-Vanilla-Sparse-GAN-Vanilla-DCGAN-VAE-dan-DDPM.git
cd Studi-Komparatif-Empiris-Model-Generatif-Autoencoder-Vanilla-Sparse-GAN-Vanilla-DCGAN-VAE-dan-DDPM
```

## 2. Install Dependensi
```bash
pip install -r requirements.txt
```

## 3. Jalankan Notebook
```bash
jupyter notebook "Tugas AE dan GAN.ipynb"
```
Jalankan semua sel secara berurutan dari atas ke bawah tanpa melewati sel mana pun, agar hasilnya sama karena random seed 42 sudah ditetapkan.
